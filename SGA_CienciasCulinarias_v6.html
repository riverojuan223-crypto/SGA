📖 Instrucciones de Uso del Sistema

🏛 SGA Ciencias Culinarias — Sistema de Gestión Académica del Programa de Ciencias Culinarias de la Universidad de Antioquia. Todos los datos se almacenan localmente en su navegador.

👥 Módulo de Estudiantes

  1. Use las pestañas para filtrar por estado (Activo, Inactivo, Práctica, Graduado).
  2. Busque estudiantes por nombre, cédula o correo en tiempo real.
  3. Haga clic en ✏ Editar para modificar datos, cambiar nivel o marcar Saber PRO.
  4. El sistema sugiere automáticamente estudiantes aptos para Saber PRO (≥113 créditos ≈ 75% del total).
  5. Los créditos aprobados se calculan sugeridos según el nivel actual; usted puede ajustarlos manualmente.
  6. Use el botón ✉️ Enviar Correo para abrir Gmail con todos los correos institucionales de estudiantes activos en copia oculta (BCC).

🧑‍🏫 Módulo de Docentes

  1. Vea todos los docentes activos e inactivos del programa.
  2. Agregue nuevos docentes con el botón ➕ Nuevo Docente.
  3. Registre disponibilidad por día y franja horaria para apoyar la programación académica.
  4. Los docentes activos aparecerán automáticamente en los menús desplegables del módulo de programación.
  5. Filtre por tipo de vinculación (Cátedra, Vinculado, Ocasional).
  6. Use el botón ✉️ Enviar Correo para abrir Gmail con todos los correos institucionales de docentes activos en copia oculta (BCC).

📅 Módulo de Programación (Corazón del Sistema)

  1. Seleccione el Nivel a programar — los cursos del plan de estudios se cargarán automáticamente con sus horas HT/HAE.
  2. Ingrese las Fechas de Inicio y Fin del semestre.
  3. Pegue los festivos (uno por línea, formato YYYY-MM-DD) — el sistema excluirá fines de semana y festivos automáticamente.
  4. Para cada curso: asigne docente, aula, día de la semana y horario.
  5. El sistema calculará y mostrará las fechas de clase, con la cédula del docente visible en la tarjeta del curso.
  6. Use ＋ Agregar fecha o ✕ en cada chip de fecha para añadir o eliminar fechas individualmente.
  7. Si un docente o aula tienen conflicto de horario, aparecerá una alerta de conflicto inmediata.
  8. La grilla semanal se actualiza en tiempo real con los bloques asignados.

🏫 Módulo de Espacios (Aulas y Laboratorios)

  1. Registre todos los espacios disponibles del programa (aulas, laboratorios, talleres, etc.).
  2. Para cada espacio, configure su disponibilidad por día y franja horaria.
  3. En cada curso, defina los requisitos de espacio (tipo, duración en horas, docentes responsables).
  4. Use el botón Generar Asignaciones para asignar automáticamente espacios a los cursos basado en disponibilidad y requisitos.
  5. El sistema muestra el nombre del aula asignada en la vista de programación de cursos.
  6. Las asignaciones se validan para detectar conflictos de uso simultáneo.

📤 Exportar e Importar

  1. Guardado automático: Los datos se guardan automáticamente en LocalStorage al hacer cambios.
  2. Respaldo JSON: Exporte todos los datos a un archivo .json para respaldo externo.
  3. Restaurar: Importe un archivo .json para restaurar datos.
  4. PDF Programación: Genera un PDF profesional con el horario del semestre.
  5. PDF Docentes: Lista completa de docentes con datos de contacto.
  6. PDF Oferta Académica Premium: Genera un PDF de diseño institucional con la oferta por nivel (código, créditos, docente, cédula, horario, fechas) y electivas. Seleccione el nivel deseado o descargue todos a la vez.

🗂️ Módulo de Historial

  1. Al finalizar un semestre, use 📦 Guardar Semestre Actual y Limpiar para archivar toda la programación del semestre.
  2. El historial guarda: cursos programados (código, nombre, créditos), docentes asignados con cédula, horarios y fechas de clase.
  3. La programación actual se limpia para comenzar el nuevo semestre. Los docentes y estudiantes no se borran.
  4. Puede consultar el historial de cualquier semestre anterior y exportarlo en PDF.
  5. Puede eliminar entradas del historial individualmente si ya no las necesita.

📅 Visualización de Fechas de Clase

  1. En la vista de programación, cada curso muestra las primeras 6 fechas de clase.
  2. Si el curso tiene más de 6 fechas, aparece un botón "+X más" clickeable.
  3. Al hacer clic en "+X más", se abre un modal con la lista completa de todas las fechas de clase.
  4. Las fechas se calculan automáticamente excluyendo fines de semana y festivos.
  5. El horario de clase es consistente según el día y horario programados.

🎓 Saber PRO — Criterios

  • El programa tiene un total de 150 créditos.
  • El umbral del 75% corresponde a ≥ 113 créditos aprobados.
  • Estudiantes en Nivel 7 o superior suelen cumplir el requisito.
  • El sistema muestra una sugerencia automática; el coordinador puede marcar manualmente.
  • Se puede filtrar estudiantes aptos en el módulo de estudiantes.

⚡ Atajos y Consejos

  • Haga clic en los encabezados de las tablas para ordenar.
  • Los festivos de Antioquia 2026 típicos: 01/01, 06/01, 23/03, 09/04, 10/04, 01/05, 25/05, 18/06, 29/06, 20/07, 07/08, 17/08, 12/10, 02/11, 16/11, 08/12, 25/12.
  • El sistema detecta conflictos de docentes y aulas en tiempo real.
  • Exporte un respaldo JSON periódicamente para mayor seguridad.

🗂️ Historial de Semestres

ℹ️ Al guardar el semestre actual, se guardará una copia de la programación de cursos y docentes en este historial. Luego se limpiará la programación para comenzar el nuevo semestre. Los estudiantes y docentes no se borran.
